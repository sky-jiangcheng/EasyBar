StatusBar Pro 隐私政策

最后更新：2026年9月3日

StatusBar Pro 不收集、存储、共享或出售任何个人数据。

数据收集

StatusBar Pro 不收集分析数据、跟踪数据、账户信息、联系信息、位置数据或标识符。

本地设备信息

StatusBar Pro 使用公共 macOS API 来显示当前时间和 Mac 上正在运行的应用程序列表。这些信息在您的设备上本地处理，不会传输到任何服务器。

权限

StatusBar Pro 请求 Accessibility 权限以检测应用状态（运行中/隐藏）。此权限仅用于读取应用状态，不访问您的文件、屏幕录制、键盘输入、网络流量、联系人、位置、摄像头或麦克风。

数据共享

由于 StatusBar Pro 不收集个人数据，因此不与第三方共享个人数据。
