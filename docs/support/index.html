常见问题

如何刷新运行中的应用列表？
点击工具栏中的刷新按钮。StatusBar 也会自动更新列表。

为什么有些 Status Bar 应用无法通过箭头按钮打开？
macOS 安全限制不允许一个 app 通过 NSRunningApplication.activate() 激活另一个 accessory app（没有 Dock 图标的 app）。这是系统限制，非 StatusBar 问题。

StatusBar 是否收集个人数据？
不。运行中的应用信息在本地处理，不会上传到任何服务器。

为什么需要 Accessibility 权限？
StatusBar 需要此权限来检测应用的运行状态（运行中/隐藏）。此权限仅用于读取应用状态，不访问您的文件或其他数据。

系统要求

StatusBar 需要 macOS 14.0 或更高版本。

Frequently asked questions

How do I refresh the list of running apps?
Tap the refresh button in the toolbar. StatusBar also refreshes the list automatically.

Why can't some Status Bar apps be opened with the arrow button?
macOS does not allow one app to activate another accessory app (an app with no Dock icon) via NSRunningApplication.activate(). This is a system limitation, not a StatusBar issue.

Does StatusBar collect personal data?
No. Information about running apps is processed on your device and never uploaded to any server.

Why is the Accessibility permission required?
StatusBar needs it to detect whether an app is running or hidden. It is used only to read app state — it never accesses your files or other data.

System requirements

StatusBar requires macOS 14.0 or later.
