常见问题

如何刷新运行中的应用列表？
点击工具栏中的刷新按钮。StatusBar Pro 也会自动更新列表。

为什么有些 Status Bar 应用无法通过箭头按钮打开？
macOS 安全限制不允许一个 app 通过 NSRunningApplication.activate() 激活另一个 accessory app（没有 Dock 图标的 app）。这是系统限制，非 StatusBar Pro 问题。

StatusBar Pro 是否收集个人数据？
不。运行中的应用信息在本地处理，不会上传到任何服务器。

为什么需要 Accessibility 权限？
StatusBar Pro 需要此权限来检测应用的运行状态（运行中/隐藏）。此权限仅用于读取应用状态，不访问您的文件或其他数据。

系统要求

StatusBar Pro 需要 macOS 14.0 或更高版本。
