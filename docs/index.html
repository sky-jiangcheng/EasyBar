StatusBar

macOS 菜单栏管理工具，自动检测并管理状态栏和 Dock 应用。

功能特性

🔍 自动检测

基于 activationPolicy 自动区分 Status Bar 和 Dock 应用

⚡ 一键操作

打开、退出、强制退出应用

📊 实时统计

Total / Status Bar / Dock 统计卡片

🔎 搜索过滤

按名称或 Bundle ID 快速搜索

App 类型

Status Bar 仅有状态栏图标，无 Dock 图标。使用 launchApplication 激活。

Dock 有 Dock 图标。使用 activate 激活。

本地运行

# 构建并运行
./script/build_and_run.sh

# 仅构建
swift build

# 运行已构建的 app
./script/build_and_run.sh run

系统要求

  • macOS 14.0+
  • Accessibility 权限（用于检测应用状态）

StatusBar

A macOS menu bar utility that automatically detects and manages status bar and Dock apps.

Features

🔍 Auto detection

Classifies Status Bar vs. Dock apps using activationPolicy

⚡ One-click actions

Open, quit, or force quit apps

📊 Live stats

Total / Status Bar / Dock counters

🔎 Search & filter

Filter instantly by name or bundle identifier

App types

Status Bar Status item only, no Dock icon. Activated with launchApplication.

Dock Has a Dock icon. Activated with activate.

Run locally

# Build and run
./script/build_and_run.sh

# Build only
swift build

# Run the already-built app
./script/build_and_run.sh run

Requirements

  • macOS 14.0 or later
  • Accessibility permission (used to detect app state)
